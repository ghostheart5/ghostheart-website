# Deal Vector public materials

Deal Vector is the working successor name to FlipMath: an Android candidate for offline USD resale estimates before selling fees. Public app release has not been announced.

## Public pages

- Product and guide: https://www.myghostheart.com/apps/deal-vector/
- Existing privacy policy: https://www.myghostheart.com/apps/deal-vector/privacy/

## Accurate feature boundaries

Enter expected sale price, purchase cost and shipping. Optional packing and purchase tax contribute to entered costs. Inspect estimated profit, break-even, margin and return on investment. Named calculations and the current draft stay on the device. The app has no account, ads or analytics. Copy and Android sharing happen only when selected.

Selling fees and unentered costs are excluded. Results are estimates, not final net proceeds or professional advice. The product page's $50 − $20 − $5 example is an illustration, explicitly labeled as not an app screenshot.

## Publication boundary

This directory contains public website material only; it does not contain the private Android source, signing credentials, a downloadable APK or an app release. Existing internal FlipMath testing does not establish availability of the new Deal Vector candidate.
